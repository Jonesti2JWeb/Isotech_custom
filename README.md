# Isotech

Sito statico in HTML, CSS e JavaScript.

## Sviluppo

```bash
pnpm install   # una volta sola
pnpm dev       # avvia il server locale su http://localhost:5173 e apre il browser
```

Le modifiche a HTML, CSS e JS vengono ricaricate automaticamente.

## Pubblicazione

Non serve alcun build: caricare sul server le cartelle `assets/`, `css/`, `js/` e i file `.html`.
